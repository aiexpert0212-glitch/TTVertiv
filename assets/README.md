# 로고 파일 넣는 곳

아래 이름으로 파일을 넣으면 화면 상단·홈·제안 리포트·푸터에 자동으로 표시됩니다.
파일이 없으면 텍스트 워드마크(UniPoint / VERTIV)가 대신 표시됩니다.

| 파일 이름 | 용도 |
|---|---|
| `logo-unipoint.svg` 또는 `.png` / `.jpg` | 회사 로고 (필수 권장) |
| `logo-vertiv.svg` 또는 `.png` / `.jpg` | Vertiv 로고 (선택) |

- 가로형 로고, **배경 투명 PNG 또는 SVG**를 권장합니다. 높이 80px 이상이면 선명하게 보입니다.
- 회사명·제품명 문구는 `js/brand.js`에서 바꿀 수 있습니다.
